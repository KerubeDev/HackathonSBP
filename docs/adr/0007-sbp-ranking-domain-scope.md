# ADR 0007: Adopt the SBP Synthetic Credit-Ranking Domain

## Status

Accepted

## Decision

The template is refined for Hackathon SBP 2026: local, synthetic AT03 credit data,
SB21/CINU classification, six macroactivity rankings, three periods, and twelve
fictitious banks. The indications document is the normative source.

## Consequences

The generic template now has a concrete domain vocabulary and a deterministic
calculation boundary. Future changes must update the context and domain ADRs.
